- 跟随使用按时间计算的指数缓动，停止移动后自动收敛，结束拖动或关闭窗口时移除渲染订阅。

# 0.3.1 贴边修复检查

- 收起按钮支持区分点击和拖动，跨屏拖动松手后按光标所在屏幕工作区的最近边吸附。
- 支持左、右、上、下四边停靠，保存屏幕及沿边位置；设置中也可手动选择。
- 透明边缘窗口绘制抗锯齿圆角，替代整数区域裁切；图标使用矢量绘制。
- 展开面板跨屏拖动期间暂停自动定位，避免 DPI 变化打断拖动。
- 25 项核心、11 项 PowerShell 集成、7 项请求检查通过。双屏四边 51 次动画、24 次收起状态、落点定位与保存恢复检查通过。
- 已检查四边按钮渲染图。测试直接调用拖动落点处理，未覆盖真实鼠标拖动的完整端到端操作；实际拖动手感仍需使用中确认。

# 0.3.0 发布检查

## 整理内容

- 正式源码位于 src，诊断与回归工具位于 Tests。
- 正式构建排除自测、截图预览、运动测试及窗口探针；构建脚本检查程序集元数据，防止诊断类型进入发布包。
- 临时预览和旧报告已归档到 artifacts；输出、压缩包和测试结果均不提交 Git。
- 清理了失效图标函数、未显示的状态控件、废弃辅助方法，并释放托盘和 COM 资源。
- 修复异常配置条目和重复收藏处理、重复切换请求争用、可选历史源不可用时的降级。
- 主面板和边缘窗口使用物理像素定位，避免不同缩放屏幕间的坐标偏移和尺寸累积放大。
- 更新 README、使用说明、版本及构建/打包/回退脚本。

## 回归范围

- 23 项核心逻辑检查：配置恢复、Unicode 路径、收藏去重、最近记录、启动注册、终端特征及会话匹配。

- 7 项真实请求处理检查：成功回执、提示符刷新失败隔离、无效路径、请求超时、输入代次、会话及焦点变化。
- 当前双屏环境的左右停靠、27 次展开/收起与反向切换、12 次收起状态采样、菜单收起、独立按钮点击命中与窗口尺寸稳定。
- 正式构建、资源加载、面板及设置渲染、发布文件与 SHA-256 校验。

结果位于 artifacts/test-results，发布以最新通过结果为准。

## 保留的限制

真实 Codex/交互式 PowerShell 的自动输入没有完成自动化端到端验收。Codex 识别仍依赖可访问性和界面特征；不确定的程序回退菜单。远程终端、管理员应用和自定义编辑模式不承诺自动输入。

测试不模拟用户登录 Windows，因此自启验证覆盖注册和启动参数，不包含重启电脑后的完整登录流程。
