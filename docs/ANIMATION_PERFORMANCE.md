# 0.3.19 动画性能记录

此页表格记录 0.3.19 的历史对照。0.3.20 已按视觉反馈改为较缓的单向滑动和固定图标交接，详情见 [发布检查](RELEASE_CHECK.md)；这些历史数据不能直接作为新版效果和时长的性能保证。

2026-11-13，同一台机器、双屏、相同用户配置，使用 Release 诊断构建运行 61 次运动回归。基线为 `b3120f8` 的动画实现，只附加与优化版相同的计时和计数代码。基线和优化版的完整运动、双屏四边末段交接检查均通过。

| 测量项 | 基线 | 优化版 |
| --- | ---: | ---: |
| 动画回调次数 | 2180 | 2037 |
| 平均回调耗时 | 1.034ms | 0.928ms |
| P95 回调耗时 | 5.728ms | 5.569ms |
| 最大回调耗时 | 30.893ms | 15.641ms |
| 回调内累计托管分配 | 2,102,112 字节 | 1,340,744 字节 |
| 窗口位置提交 | 535 次 | 466 次 |
| 裁切区域提交 | 2432 次 | 1921 次 |

裁切提交减少约 21%，累计分配减少约 36%。回调耗时使用 Stopwatch 测量墙钟时间，包含系统调度影响，不代表 CPU 使用率；最大值和 P95 尤其容易受其他程序影响。优化版前一次完整回归平均耗时为 0.846ms，不能把单次结果视为稳定保证。

动画基于实际经过时间采样，回调总数会随刷新率、调度及轨迹收敛变化。计时仅覆盖 WPF 动画回调，托管分配仅统计该回调所在 UI 线程；位置和区域计数覆盖整轮运动检查。没有测量 DWM/GPU 呈现延迟、实际显示丢帧或真人感受。

## 效果与实现

- 从静止开始时保留零初速，较早展开主体，再平滑减速；展开收敛略快于收起。
- 快速反向切换接续最后显示的位置和速度，先消除原方向惯性再转向；限制可见位置，不弹跳出边界。短距离切换不再压成一帧。
- 使用解析式直接计算运动，不依赖固定帧数，不通过增加定时器频率追帧。单元检查覆盖 30/60/120/144/240Hz 采样和连续反转。
- 保留主 HWND 尺寸、内容树和面板位置；按像素去重裁切和浮动位置提交，缓存停靠方向样式。同一合成时刻只更新一次。
- 末段仍使用已绘制的透明边缘窗口完成交接；保持最终逐像素一致、内容就绪等待、无动画及浮动模式行为。
- 动画完成后移除 Rendering 回调；额外调用不再执行窗口更新。性能采样和列表只存在于 Tests 诊断代码。

## 复测

运行 `pwsh -NoProfile -File Tests/Run-Tests.ps1`。运动结果中的 `AnimationPerformance` 包含回调计时、分配和原生提交计数；`UnchangedGeometrySkipsNativeUpdates`、`NoIdleAnimationUpdates` 检查重复几何和空闲行为。`tail-test-results.json` 保留双屏四边的透明度、裁切、坐标和末帧像素一致性判定。

本轮原始对照保存在 `artifacts/test-results/animation-baseline-motion.json`，最终结果在 `artifacts/test-results/motion-test-results.json`。这些是本机生成文件，不进入版本库。
