# PathDock

Windows 目录快捷工具。解压到固定位置，双击 `PathDock.exe` 启动。

精简包（framework-dependent）需要 .NET 8 Desktop Runtime，架构须与发布包一致。自带运行环境包（portable）无需预装。

- 点击屏幕边缘的蓝青色按钮展开；无操作 3 秒自动收起。点击面板外部会在短暂缓冲后收起，期间返回面板可取消。
- `Ctrl + Alt + 空格` 展开或收起。顶部图钉可保持展开。
- 固定区显示名称，悬停查看完整路径；最近区最多显示 10 条完整路径。屏幕空间不足时可用鼠标滚轮查看；重新展开会回到列表顶部。
- 可以拖入文件夹。右键目录选择打开、粘贴、收藏或编辑。
- 顶部 `…` 设置点击行为或打开设置。
- 托盘菜单提供开机自启、设置和退出，双击托盘图标也可展开。

## 自动动作

自动模式下，非输入区域打开目录；可编辑文本框或识别成功的 Codex 输入区粘贴路径，不发送回车。已有文字会保留，在当前光标处插入。

无法确认终端状态时显示操作菜单。粘贴会使用并保留剪贴板中的路径；请先选择目标输入位置。管理员窗口使用复制路径。

## 文件对话框跟随

在设置中开启“文件对话框跟随资源管理器”。浏览资源管理器的目录后，新打开标准文件对话框或返回原对话框时，自动切换到该窗口活动标签页的目录，保留文件名和文件类型筛选。浏览记录在两分钟内有效。

该选项默认关闭。支持同等权限的 Windows 标准打开、保存及文件夹选择框，旧式或自定义对话框和虚拟位置按兼容性规则跳过。继续输入、焦点变化或请求过期时取消本次跟随。

## PowerShell

如需切换当前终端目录，在设置中启用 PowerShell 集成，然后新开 PowerShell 7 标签。空闲标签标题会显示 `[PD:…]` 标记，用来匹配会话。保留固定标题或无法识别时，可右键选择会话。

仅在没有未提交输入、未运行命令的空提示符下切换。集成会备份并追加用户 profile，保留现有提示符和按键设置。设置中取消后，重启已打开的会话生效。

## 自启与数据

托盘右键菜单中的“开机自启”仅影响当前 Windows 账户，默认关闭。未固定面板时，自启只显示边缘按钮。

收藏和偏好保存在 `%LOCALAPPDATA%\PathDock`。更新时替换程序文件，不必删除数据。启用自启或 PowerShell 集成后，请保持程序目录固定；移动前先关闭相应选项。

PowerShell 集成功能需要 PowerShell 7。

- 收起后可直接拖动边缘按钮，松手会吸附到光标所在屏幕最近的边（左、右、上、下）；位置自动保存。展开时也可拖动标题。
- 多屏使用各屏工作区，避开任务栏。

- 展开时拖动顶部 PathDock 标题区域，可把面板放到任意屏幕位置并自动保存。展开面板与边缘按钮互斥显示。收起后仍使用最近边停靠；拖动边缘按钮可恢复面板随边停靠。

- 面板展开后，3 秒无操作会自动收起；点击面板外部会立即收起。固定面板时保持展开，设置和菜单打开期间暂停自动收起。

- 面板动画跟随 Windows 的动画效果设置；系统关闭动画时直接展开/收起。后台发现目录会在操作空闲时更新列表。
